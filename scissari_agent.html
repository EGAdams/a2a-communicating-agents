A2A JSON-RPC Flow

Structured tasks with statementPath · streaming · task polling

Use the A2A HTTP endpoint for structured output, streaming, or when you need to track task state. All financial skills run through this path.

Step 1 — SendMessage

POST http://10.0.0.143:9001/
Content-Type: application/json

{
  "jsonrpc": "2.0",
  "method": "SendMessage",
  "id": "my-task-1",
  "params": {
    "message": {
      "role": "ROLE_USER",
      "parts": [{ "text": "Summarize the January statement" }]
    },
    "skill": "summarize_statement",
    "context": {
      "statementPath": "/home/adamsl/rol_finances/.../chase_jan.txt"
    }
  }
}

Step 2 — Poll GetTask

POST http://10.0.0.143:9001/
{
  "jsonrpc": "2.0",
  "method": "GetTask",
  "id": "poll-1",
  "params": { "id": "<task-uuid-from-step-1>" }
}
// States: SUBMITTED → WORKING → COMPLETED (or FAILED)
// result.result holds Jeri's answer when COMPLETED

Task State Flow

SUBMITTED → WORKING → COMPLETED / FAILED

Streaming (SSE) — SendStreamingMessage

POST http://10.0.0.143:9001/
{
  "jsonrpc": "2.0",
  "method": "SendStreamingMessage",
  "id": "stream-1",
  "params": { /* same params as SendMessage */ }
}
// Response: text/event-stream SSE
// data: {"type":"chunk","taskId":"...","content":"token..."}
// data: {"type":"done","taskId":"...","status":"COMPLETED"}

Decision Guide

When to use Letta native messaging vs A2A HTTP

SituationUse
Quick question about a statement or the SDK Letta native — send_letta_message
Need structured JSON (transactions, anomalies) A2A SendMessage + GetTask poll
Want output as it streams token by token A2A SendStreamingMessage (SSE)
Background task — fire and check later A2A SendMessage → store task ID → poll later
Cancel an in-flight task A2A CancelTask
Discover Jeri's capabilities programmatically GET /well-known/agent.json (AgentCard)

Start / Stop

Shell commands to manage Jeri's A2A server on Mom's Machine

The Letta agent is always registered. The A2A HTTP server must be started separately from /home/adamsl/claude-code-sdk-ts:

Start

# From /home/adamsl/claude-code-sdk-ts
cd agents/jeri && bash start_jeri_agent.sh

Stop

bash stop_jeri_agent.sh

Development Mode (hot reload)

npx tsx /home/adamsl/claude-code-sdk-ts/agents/jeri/index.ts

Register in Letta (first-time only)

# From /home/adamsl/claude-code-sdk-ts, with rol_finances venv active
python3 create-letta-agent.py
Note: Jeri's A2A server at http://10.0.0.143:9001 must be running for all five financial skills to work. Verify with GET http://10.0.0.143:9001/health before delegating tasks.
